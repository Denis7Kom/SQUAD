# SQUAD Command

Статический локальный прототип командного центра. Совместим с GitHub Pages, сборка и зависимости не нужны.

## Публикация

1. Откройте **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку `codex/squad-foundation`, папку `/(root)` и нажмите **Save**.
4. Дождитесь завершения публикации. Адрес сайта появится в разделе Pages.

## Возможности

- Создание нескольких локальных команд и двух деревьев подчинения, добавление и удаление участников.
- Справочник званий на русском и английском, описания и согласованные пороги для командиров от майора.
- Расчёт взвешенного отзыва и его локальное сохранение и редактирование.
- Одна локальная кандидатура и отзыв заявки.
- Локальные черновики жалоб.

Коэффициенты оценки — предварительные. Порог для генерала — 23 балла; минимальные количества отзывов и другие пороги ещё не утверждены. Автоматическое присвоение званий и проверка допуска не реализованы. Символы званий условные; техническая ветка не определена.

## Важно

Данные сохраняются в localStorage браузера; другие пользователи их не увидят. Очистка хранилища или смена устройства удалит доступ к данным. Отзыв — один на участника **в текущем браузере**, а не подтверждённая оценка реального автора. Проверить самооценку, надёжно ограничить голосование или объединить оценки пользователей без общей базы и идентификации невозможно. Заявки и жалобы никуда не отправляются. Голосование и модерация не реализованы.
