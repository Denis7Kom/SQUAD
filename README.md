# SQUAD Command

Демонстрационный статический сайт для GitHub Pages. Для запуска не нужны сборка или зависимости.

## Публикация

1. В настройках репозитория откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. В поле **Branch** выберите `codex/squad-foundation`, папку `/(root)` и нажмите **Save**.
4. Дождитесь завершения развёртывания. Итоговый адрес появится в разделе Pages.

## Возможности и ограничения

Сайт показывает командирские и солдатские звания, пояснения к командирским званиям и калькулятор оценки. Веса критериев пока демонстрационные. Символы званий — временные номера.

Это прототип: профили, постоянные структуры команд, сохранение и редактирование отзывов, жалобы, подача кандидатур и голосования не реализованы. GitHub Pages размещает статические файлы; для общих данных потребуется отдельно подключить серверную часть и базу данных.
