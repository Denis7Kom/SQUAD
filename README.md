# SQUAD COMMAND

Неофициальный проект сообщества для наглядного представления состава команд, званий, специализаций и распределения ответственности в игре SQUAD.

## Текущий статус

Это **статический локальный прототип**, предназначенный для GitHub Pages. Серверной части и общей базы данных нет. Команды, отзывы, кандидатуры, история решений и черновики жалоб сохраняются в `localStorage` текущего браузера и не синхронизируются между игроками. Очистка данных браузера или переход на другое устройство может привести к потере доступа к записям.

Примеры составов, отзывов, кандидатур и обращений содержат вымышленные данные. Они не подтверждают игровые результаты или реальные назначения.

## Что доступно

- Три вида структуры: «Сквадлидеры», «Солдаты» и общее дерево; масштабирование, перемещение и сворачивание ветвей.
- Несколько примерных составов и создание локальных команд; проверки размера команды и лимитов командирских мест. Подчинение командиров автоматически подстраивается под ближайшего доступного руководителя направления.
- Отдельные роли советника, бойцов и специалистов по технике; выбор специальности и необязательное указание кода друга или ссылки Steam.
- Справочник званий и локальные формы взвешенных оценок командиров, бойцов и специалистов по технике.
- Отображение согласованных порогов допуска, несколько локальных заявок, привязанных к выбранной команде, демонстрационные назначения и передача командования, а также локальные черновики жалоб.
- Двуязычные правила применения ресурса с возможностью печати.
- Основа PWA: манифест, PNG-иконки 192 × 192 и 512 × 512 и service worker для кеширования файлов интерфейса. Установка, обновление и работа без сети на разных устройствах требуют проверки.

Проверки, выполняемые в браузере, не являются системой безопасности. Существующие локальные записи, созданные до изменения правил, могут требовать ручного исправления.

## Что ещё не реализовано

- Общие профили, идентификация авторов и разграничение прав.
- Общие независимые отзывы, усреднение оценок разных авторов и автоматическая проверка допуска.
- Настоящее голосование, подсчёт голосов, проверка победителя и автоматическое назначение.
- Подписанные и проверяемые сертификаты, приём жалоб и модерация.
- Перенос данных между устройствами и резервное копирование через интерфейс.

Локальная заявка не отправляется другим игрокам. Демонстрационный сертификат не подтверждает победу или назначение. Кандидаты в советники выбираются из действующих командиров от майора; рекомендации по тактике используют доступные оценки и не являются дополнительным условием назначения. Период полномочий фиксируется в заявке. Голоса сохраняются только локально и не подтверждают ни личность голосующего, ни итог выборов. При демонстрационной передаче командования возможные преемники сортируются по доступной репутации; общий рейтинг, допуск и победа на выборах не проверяются автоматически.

## Файлы

- `index.html` — интерфейс, стили и клиентская логика.
- `manifest.webmanifest`, `sw.js`, `favicon.svg`, `icon-192.png`, `icon-512.png` — основа PWA и иконки.
- `LICENSE` — условия использования проекта.
- `SECURITY.md` — порядок сообщения о возможных уязвимостях.

## Запуск и публикация

Для ознакомления откройте `index.html` в браузере. Для проверки service worker и PWA нужен HTTPS либо локальный HTTP-сервер на `localhost`.

При использовании GitHub Pages в настройках **Settings → Pages → Build and deployment** выберите **Deploy from a branch**, ветку `codex/squad-foundation` и папку `/(root)`. Сохраните настройки и проверьте статус развёртывания в GitHub. Изменения в ветке не гарантируют, что она уже выбрана источником публикации.
