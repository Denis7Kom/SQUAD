# План испытаний и приёмки

Статус: проект. Все результаты ниже — ожидаемые, а не фактически пройденные тесты. Для каждого запуска записывать версию, окружение, исполнителя, дату, шаги, фактический результат и ссылку на дефект. Исправление проверять повторно.

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| AT-01 | Два участника входят с разных устройств | Видят один согласованный состав и данные, разрешённые их ролям |
| AT-02 | Два запроса одновременно занимают последнее место | Сервер допускает не более установленного лимита; результат согласован после обновления |
| AT-03 | Командир назначен подчинённым равному званию | Сервер отклоняет операцию и объясняет причину |
| AT-04 | У прапорщика выбран несовместимый руководитель экипажа | Сервер отклоняет; сценарий уточнить после D-04 |
| AT-05 | Игрок оценивает себя или отправляет второй отзыв того же типа | Самооценка запрещена; второй отзыв заменяет или редактирует существующий согласно согласованной области |
| AT-06 | Два автора отправили оценки | Средний результат и число отзывов соответствуют утверждённой формуле; отсутствие не равно 0 |
| AT-07 | Пользователь без права голоса отправляет запрос напрямую | Сервер отказывает; голос не создаётся |
| AT-08 | Один избиратель голосует дважды, включая параллельные запросы | Учитывается не более допустимого числа голосов; политика изменения голоса согласована |
| AT-09 | Заявка вне порогов или одновременно с другой активной | Решение соответствует утверждённым ограничениям D-05 |
| AT-10 | Срок должности истёк | Должность и история отображаются согласно утверждённой политике, в том числе при отсутствии посетителей |
| AT-11 | Пользователь без полномочий запрашивает жалобу | Доступ запрещён, содержимое не раскрывается |
| AT-12 | Открыть документ и подтвердить ознакомление | Служебные подписи неизменяемы пользователем; подтверждение привязано к согласованной версии |
| AT-13 | Дерево на телефоне и ПК, RU/EN | Читаемо, управление масштабом и ветвями работает, текст не обрезан; кнопка у Генерала отсутствует |
| AT-14 | Установить PWA и обновить приложение | Поведение и офлайн-ограничения соответствуют согласованной матрице браузеров |
| AT-15 | Восстановить отдельную тестовую копию из бэкапа | Сверены контрольные данные, доступы и время восстановления без изменения рабочей базы |
| AT-16 | Перевести локальные данные в тестовую среду | Дубликаты и ошибки обнаружены, контрольные суммы/числа сверены, откат проверен |

Для выпуска согласовать допустимые браузеры, устройства, нагрузку, уровни доступности, серьёзность дефектов и критерии окончательного одобрения.
