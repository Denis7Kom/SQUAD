# Матрица ответственности RAT и RACI

Статус: предварительное толкование RAT как таблицы ответственности; расшифровка пользователя не подтверждена (D-12). RACI: R — исполняет; A — отвечает за итог и утверждает; C — консультирует; I — информируется. Один человек может совмещать роли. Участники кроме владельца ещё не назначены.

| Действие | Владелец | Разработчик | Тестировщик | Оператор сервиса |
|---|---|---|---|---|
| Цель, бюджет, приоритеты | A/R | C | I | I |
| Утверждение правил и требований | A | R | C | C |
| Проектирование и код | A | R | C | C |
| Проверка безопасности и приёмка | A | R | R | C |
| Резервное копирование и восстановление | A | R | C | R |
| Развёртывание и эксплуатация | A | R | C | R |
| Обработка жалоб | A | C | I | R |
| Решения по правам на материалы | A/R | C | I | I |

Конкретные люди, доступы, замещение, порядок согласования и сроки реагирования определяются до реальной эксплуатации. Назначение ответственности в этой таблице не подтверждает заключения договора.
