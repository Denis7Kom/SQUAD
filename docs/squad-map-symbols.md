# Squad map symbols

The tank and tracked IFV symbols embedded in `warMapGlyph` are original map images exported from the Squad SDK, provided by https://github.com/frobinsonj/squad-json (images/icons/map/tank.png and trackedifv.png). Source commit: bb49bc013ad0ec6bd00f665ba84fffb127090b90
