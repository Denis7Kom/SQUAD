# Текущее состояние и инвентаризация

Основание: [снимок 752c835](https://github.com/Denis7Kom/SQUAD/tree/752c8359eb9ce68fbed4c10cf1ffed2db546dd3c). Проверены состав файлов, README и отдельные фрагменты index.html; полный динамический аудит и тестирование в браузере не проведены.

## Состав
- index.html — HTML, CSS и клиентская логика; код и оформление сосредоточены в одном файле.
- manifest.webmanifest, sw.js, favicon.svg и две PNG-иконки — основа PWA. Установка и офлайн-работа требуют проверки.
- supabase/README.md и migrations/202610290001_initial_foundation.sql — заготовка серверной части. Наличие миграции не доказывает её применения и подключения сайта.
- README.md, SECURITY.md, LICENSE — описание, порядок сообщения об уязвимостях и уведомление о правах.

## Данные и функции
README называет систему статическим локальным прототипом: составы, оценки, заявки, решения и черновики жалоб находятся в localStorage браузера. Общая база, авторизация и настоящее совместное голосование не заявлены как работающие. Данные примеров вымышлены. Переход в другой браузер или очистка локальных данных могут сделать записи недоступными.

Интерфейс содержит общее дерево, представления сквадлидеров и солдат, масштабирование, ветви, специальности, локальные формы и правила на русском и английском. Все сценарии требуют отдельной проверки, включая мобильный экран.

## Значения, обнаруженные в коде
- rankLimits: генерал 1, полковник 1, подполковник 1, майор 2, капитан 3. Это расходится с ранее сообщёнными 1/1/2/3/6 — см. D-01.
- Формы оценок содержат отдельные критерии командиров, солдат и техники. Значения порогов записаны в [реестре требований](03-requirements.md).
- Разметка документа по-прежнему содержит кнопки «Поставить подпись» и «Очистить» для служебных подписей. Ранее владелец просил убрать возможность их замены и отдельно дать пользователю подписать ознакомление — D-02.
- В правилах сайта описана выборность Советника из командиров от майора голосами капитанов и выше; в истории также упоминалось решение Генерала. Согласовать механизм D-03.

Наличие коммита сохраняет ссылку на код, но не является независимой резервной копией браузерных данных, секретов, внешних сервисов или настроек GitHub Pages.
